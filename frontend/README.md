# Online Learning Platform Frontend

A React + Vite frontend for the Online Learning Platform backend.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` and configure API URL.
3. Start the development server:
   ```bash
   npm run dev
   ```

## Environment

- `VITE_API_BASE_URL` — backend API base URL (for example `http://localhost:5000`)

## Pages

- `/login`
- `/register`
- `/dashboard`
